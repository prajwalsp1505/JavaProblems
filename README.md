## 💡 Key Insights

### Time Complexity Cheat Sheet
```
O(1) - Constant Time (Best)
O(log n) - Logarithmic (Binary Search)
O(n) - Linear (Single Loop)
O(n log n) - Linearithmic (Sorting)
O(n²) - Quadratic (Nested Loops)
O(2^n) - Exponential (Recursion)
O(n!) - Factorial (Permutations)
```

### Common Patterns
- **Two Pointer Technique:** Used in problems like Two Sum, Container With Most Water
- **Sliding Window:** Substring problems, Fixed-size window problems
- **Binary Search:** Sorted array search problems
- **BFS/DFS:** Tree and Graph traversal
- **Dynamic Programming:** Optimization problems with overlapping subproblems
